trim

        
space play / pause the selection

        
< > (or , .) step one frame

        
j l step one second

        
i / o set start / end at the playhead

        
drag the top edge of the selection to slide it · { } nudge it a frame

        
home / end jump to start / end

        
type times as 12.5 or 1:02.5

        
output

        
f switch between exact (re-encode) and fast (lossless copy, keyframe cuts)

        
m mute · e export · v open another video

      

      

        
crop

        
drag on the video to draw a crop · drag inside to move it · corners resize

        
1–8 free, original, 16:9, 4:3, 1:1, 4:5, 9:16, 21:9

        
←↑↓→ move the crop (shift = 10×)

        
+ / - make the crop bigger / smaller

        
0 no crop · x center it

        
c switch between editing and seeing the result

        
cropping always re-encodes, so fast mode turns off while there's a crop
